## Overview

Wikithis adds a right-click context menu option to every item in Terraria's inventory that opens the Official Terraria Wiki page for that item in the system browser, providing instant access to drop sources, crafting recipes, spawn conditions, and lore — eliminating the need to manually search the wiki.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Wikithis** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Right-Click Wiki** | Right-click any inventory item to open its Official Wiki page instantly |
| **Full Item Coverage** | Works with all vanilla items, blocks, accessories, and equipables |
| **Mod Item Support** | Third-party mods can register their own wiki URLs for their items |
| **Browser Integration** | Opens directly in your system default browser with correct search |
